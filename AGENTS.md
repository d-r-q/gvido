# Инструкции для агентов

Это локальное расширение GNOME Shell. Исходники виджета находятся в `runtime.js`, оформление — в `theme.css`, загрузчик — в `extension.js`.

Перед изменениями проверяйте, не отличаются ли исходники от установленной копии расширения. Не перезаписывайте несвязанные правки пользователя.

После изменений проверяйте синтаксис JavaScript командой `node --check` для изменённых файлов и запускайте изолированные проверки `./tests/run-headless.sh`. Подробное описание тестов, ограничений и артефактов: [agents/test-helpers.md](agents/test-helpers.md).

Тестовые файлы не включаются в установленное расширение. Не запускайте проверки на пользовательском `~/todo.md` и не считайте результаты изолированной GNOME Shell подтверждением поведения живой сессии без отдельной проверки.
